## English

### 🌟 Overview

PDF Tools is a modern, secure, and completely free online PDF processing platform. All PDF operations are performed locally in your browser, ensuring 100% privacy and security.

### ✨ Key Features

- 🔒 **100% Secure & Private** - All processing happens locally in your browser. Files are never uploaded to servers.
- ⚡ **Lightning Fast** - Local processing ensures millisecond response times.
- 💰 **Completely Free** - No registration, no limits, no watermarks.
- 🌍 **Multi-language Support** - Available in 10 languages with more coming soon.
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices.
- 🛡️ **No Data Collection** - Your files are processed and forgotten immediately.

### 🛠️ Available Tools

| Tool | Description |
|------|-------------|
| 🔗 **Combine PDF** | Merge multiple PDF files into one document |
| ✂️ **Split PDF** | Split PDF files into multiple documents |
| 📄 **Extract Pages** | Extract specific pages from PDF |
| 🗜️ **Compress PDF** | Reduce PDF file size while maintaining quality |
| 🔄 **Rotate PDF** | Rotate PDF pages to any angle |
| 🗑️ **Delete Pages** | Remove unwanted pages from PDF |
| 🔀 **Reorder Pages** | Rearrange PDF pages in any order |
| 💧 **Add Watermark** | Add text or image watermarks to PDF |
| 📦 **Batch Process** | Process multiple PDF files at once |
| 🔐 **Encrypt PDF** | Add password protection to PDF |
| 🔓 **Decrypt PDF** | Remove password protection from PDF |

### 🚀 Quick Start

#### Development Server

```bash
# Install dependencies
npm install

# Run development server (http://localhost:3000)
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
